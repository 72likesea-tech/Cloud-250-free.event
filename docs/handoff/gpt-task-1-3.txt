[프로젝트 공통 컨텍스트]

나는 개인용 Android 영어회화 앱을 Windows PC에서 개발한다. 앱스토어 출시 없이 내 휴대폰에 APK로 직접 설치한다. 개발에는 Claude(총괄·구현), Gemini(앱 내 AI 대화·음성 엔진), GPT(대화 콘텐츠·검수) 세 모델을 나눠 쓴다. 너의 역할은 별도로 지정한다.

[최우선 요구사항 — 작업지시서보다 우선]
내가 지정한 요일·시간이 되면, 휴대폰이 잠겨 있거나 내가 앱을 만지고 있지 않아도 앱이 스스로 깨어나서 먼저 영어로 자연스럽게 음성으로 말을 건다. 내가 아무 조작을 하지 않아도 앱이 먼저 대화를 시작해서 영어 대화를 강제로 시도하고 연습하게 만드는 것이 이 앱의 존재 이유다. 앱이 먼저 말하고, 내 대답을 듣고, 다시 응답하는 흐름이 자동으로 이어져야 한다.

[작업지시서에서 유지되는 조건]
- 지정 시간 알림·수업 시작은 PC나 개발 도구를 꺼 둔 상태에서도 휴대폰 단독으로 동작해야 한다. 온라인 AI 대화에는 인터넷이 필요할 수 있다.
- 운영비는 월 0원(무료 티어)을 목표로 한다. 유료 자동 전환, 무제한 재시도, 키 바꿔치기로 한도 우회는 금지.
- 한도 초과·오프라인·오류 시 입력을 잃지 않고 상태를 설명하며, 내장 '기본 연습'으로 전환할 때는 그것이 AI 응답이 아님을 표시한다.
- API 키는 소스·APK·로그·문서에 하드코딩하지 않는다. 기기에 입력해 Android Keystore로 보호한다.
- 반복 백그라운드 작업(WorkManager 등)이 아니라 AlarmManager 정확 알람을 예약의 주 수단으로 쓴다. 재부팅·시간대 변경·앱 업데이트 후 예약을 복원한다.
- 기술 기본안: Kotlin + Jetpack Compose, AlarmManager, Android TextToSpeech / SpeechRecognizer, 무료 티어 텍스트·음성 AI API, 기기 내 저장(DataStore/Room).
- 완료 기준은 빌드 성공이 아니라, 실제 휴대폰에서 지정 시각에 앱이 먼저 말을 걸고 → 내가 대답하고 → 한 회차를 끝내고 → 기록이 저장되는 것을 확인하는 것이다.

[작업지시서와 추가요구사항이 충돌하는 지점 — 추가요구사항 쪽으로 해석]
- 작업지시서는 '알림을 누르면 수업 시작'과 '마이크는 사용자가 화면에서 시작한 뒤 사용'을 기본으로 했다. 추가요구사항은 이를 뒤집는다: 알람 시각에 앱이 자체적으로 화면을 켜고(잠금화면 위 전체화면 진입), 첫 문장을 음성으로 재생하고, 그 직후 자동으로 듣기를 시작한다.
- 단, Android가 기술적으로 막는 부분(강제 중지 상태, 제조사 절전 종료, 권한 미허용)은 우회하지 말고 '사용자가 해야 할 설정'으로 안내한다. 가능한 한 자동, 불가능한 부분은 정직하게 표시.

[답변 규칙]
- 한국어로 답한다. 코드·프롬프트·API 명세는 영어 그대로 둔다.
- 확인되지 않은 Android 정책, 모델 이름, 가격, 한도는 추측하지 말고 "확인 필요"로 표시하고 확인 날짜를 적는다.
- 다른 모델에 넘길 산출물은 복사해서 붙일 수 있는 하나의 코드 블록 또는 표로 낸다.

[인터뷰로 확정된 값 — 2026-09-26]
- 기기: Galaxy S24 Ultra, One UI 8.5, Android 16. 사용 국가 한국. 사이드로드 APK로 설치.
- 학습자: 영어 초급 상 ~ 중급 하. 목적은 여행·업무·일상·비즈니스·토론 전 영역. 한국어는 막힐 때 말문을 여는 용도로만.
- 일정: 매일 14:00에 첫 말걸기. 하루 1회(N=1), 한 회차 5~10분, 약 10왕복(M=10).
- 재시도: 패스·대답 없음·무음 모드·방해금지 무반응이면 1시간 뒤 재시도, 20:00까지. 그날 회차를 끝내면 다음 날 14:00.
- 대답 없음: 8초 기다린 뒤 1회만 다시 말걸기 → 그래도 없으면 종료.
- 무음(매너) 모드: 말을 걸지 않음. 방해금지: 소리 없이 화면+진동, 터치하면 시작(30초 무반응이면 종료).
- 대화 시작: 첫 인사 → 오늘 주제를 영어로 묻는다. 선택지는 "work(비즈니스·업무)", "travel(여행·일상)", 그리고 그날의 구체적인 토론 질문 하나(예: "Should companies adopt a four-day work week?"). '의견과 토론'이라는 이름으로 묻지 않고 토론 질문 자체를 바로 제시한다.
- 교정: 대화 중에는 흐름을 끊지 않고 자연스러운 표현으로 한 번 되받아 말하기(recast). 회차가 끝나면 한국어 교정 요약 3개.
- AI: 사용자가 이미 만든 Gemini API 키(결제 미연결, 월 0원 필수). 대화 응답과 종료 후 요약 모두 gemini-2.5-flash-lite 예정(확인 필요).
- 외부 전송: 음성을 글자로 바꾼 대화 텍스트만 Gemini로 보냄. 음성 원본은 저장하지 않음.
- 2단계(잠긴 휴대폰에서 14:00에 화면이 켜지고 첫 문장이 소리로 나옴)는 구현 완료, 실기기 검수 중.

[너의 역할: 대화 콘텐츠 설계자 + 학습 설계자 + QA 리뷰어]

너는 코드를 작성하지 않는다. 이 앱이 내게 먼저 말을 걸고 대화를 이어가는 '내용'과 '학습 규칙'을 설계한다. 산출물은 Android 앱의 assets/에 들어갈 JSON과, 대화 엔진 시스템 프롬프트에 반영될 규칙 문서다.

내 정보: 영어 수준 초급 상~중급 하, 목적 여행·업무·일상·비즈니스·토론 전 영역, 관심 주제 3개(① 비즈니스와 업무 ② 여행과 일상 ③ 의견과 토론), 하루 1회, 회차당 약 5~10분(약 10왕복), 지정 시간 매일 14:00(무응답·패스 시 15:00~20:00 사이 1시간마다 재시도).

이번에는 작업 1과 작업 3만 해라. 작업 2(콘텐츠 팩 JSON), 작업 4(QA 체크리스트), 작업 5(코드 리뷰)는 나중에 따로 요청한다.

작업 1. 페르소나와 먼저 말 걸기 규칙
- 앱이 갖출 대화 상대 페르소나를 2~3개 제안하고 하나를 추천해라(이름, 말투, 다정함 정도, 유머 수준). 잠긴 휴대폰에서 오후에 갑자기 음성이 나오는 상황이므로, 첫 문장은 놀라지 않게 자연스럽고 짧아야 한다.
- 오프닝 문장(첫 인사 + 오늘 주제 질문)을 40개 써라. 구성: 첫 시도(14시)용 20개, 재시도(15~20시, "아까 바빴지?" 같은 뉘앙스 포함 가능)용 10개, 주말용 10개. 각 문장은 반드시 한 번의 질문으로 끝나고, 그 질문은 "work, travel, 또는 {debate_question}" 세 선택지를 묻는다. {debate_question} 자리는 그날의 구체적 토론 질문이 들어갈 자리표시자로 남겨라. '의견과 토론(opinion and debate)'이라는 말은 쓰지 마라.
  예: "Hey, it's English time! Want to chat about work, travel, or this one: {debate_question}"
- 토론 질문 후보 30개를 써라. 초급 상~중급 하가 찬반과 이유 한두 개로 답할 수 있는 수준, 한 문장, 일상·직장·기술·사회 분야를 고르게.
- 사용자가 대답하지 않을 때 다시 말 거는 문장(1차 재말걸기) 5개와, 그래도 대답이 없을 때 부담 없이 마무리하며 "1시간 뒤 다시 올게" 뉘앙스를 담은 마지막 문장 5개를 써라. (재말걸기는 1회만 한다.)
- 사용자가 한국어로 답하거나 "모르겠어"라고 할 때 쉬운 영어로 다시 유도하는 문장 10개. 필요하면 한국어 힌트 한 줄을 붙이되, 영어로 말문을 여는 것이 목적이다.

작업 3. 교정 규칙과 회차 완료 기준
- 교정 방식은 이미 정해졌다: 대화 중에는 흐름을 끊지 않고 자연스러운 표현으로 한 번 되받아 말하기(recast), 회차 끝에 한국어 교정 요약 3개. 이 전제 안에서 문법·표현 중 무엇을 우선 recast할지, recast하지 않고 넘길 실수는 무엇인지 규칙을 써라. 음성 인식 결과만으로 발음을 평가하지 않는다(인식 오류와 실제 실수를 구분하는 기준도 적어라).
- 회차 끝 '교정 요약 3개'를 고르는 기준과 출력 형식(내가 한 말 → 더 자연스러운 표현 → 한국어 한 줄 설명)을 정해라.
- 회차 완료 기준(기본안: 5분 이상 또는 약 8왕복 이상이면 완료, 10분에 자연스럽게 마무리), 너무 어려울 때/쉬울 때 난이도를 조절하는 신호와 규칙, 복습에 넘길 표현을 고르는 기준을 표로 정리해라.
- 이 규칙을 대화 엔진 시스템 프롬프트에 들어갈 영어 문단(200단어 이내)으로도 써라. Gemini 담당에게 넘긴다.

산출물은 작업마다 복사해 붙일 수 있는 하나의 블록으로 내라. 작업 1부터 시작해라.
