개인용 영어회화 앱 개발 작업지시서
Windows 개발 환경에서 요구사항 인터뷰를 진행한 뒤, 사용자의 Android 휴대폰에 직접 설치할 영어회화 학습 앱을 개발한다. 정해진 시간에 학습 알림을 보내고, 사용자가 알림을 누르면 해당 수업이 바로 시작되는 경험을 구현한다. 세부 기능과 학습 방식은 아래 인터뷰를 통해 확정한다.
1 사용 방법과 기본 요구사항
문서 사용 방법
사용자는 Windows PC에서 앱을 만들 프로젝트 폴더를 열고, Claude 또는 Codex에 이 문서 전체를 전달한다. 이미 작업 중인 프로젝트가 있다면 해당 폴더에서 시작한다. 문서를 받은 개발 도구는 아래 지시를 따라 인터뷰부터 진행한다.
첫 요청 문장
“첨부한 작업지시서에 따라 개인용 Android 영어회화 앱을 만들어 주세요. 먼저 현재 프로젝트와 개발 환경을 읽기 전용으로 확인하고, 제 요구사항을 한국어로 인터뷰해 주세요. 한 번에 1~3개씩 질문하고, 어려운 선택에는 추천안과 이유를 알려 주세요. 인터뷰 결과를 정리해 확인받은 다음, 실제 휴대폰에 설치하고 검수할 수 있을 때까지 개발을 진행해 주세요.”
확정된 기본 요구사항
개발은 사용자의 Windows PC에서 진행한다. Claude 또는 Codex는 개발을 돕는 도구로 사용한다.
앱은 개인용 Android APK로 제공한다. 앱스토어 출시는 범위에 포함하지 않는다.
사용자가 정한 요일과 시간에 학습 알림이 자동으로 표시되어야 한다.
알림을 누르면 그 알림에 연결된 수업으로 바로 이동한다. 매번 홈 화면에서 수업을 다시 선택하게 하지 않는다.
운영 비용은 가능한 한 무료 티어 안에서 유지한다. 유료 결제나 구독을 기본 전제로 삼지 않는다.
설치 후 일상적인 학습과 예약 알림은 Windows PC나 개발 도구를 켜 두지 않아도 동작해야 한다. 온라인 AI 대화에는 인터넷이 필요할 수 있다.
진행 원칙
인터뷰를 먼저 한다. 학습자의 수준, 일정, 대화 방식, 디자인을 임의로 확정하지 않는다. 아래에 제시된 기본안은 인터뷰를 돕기 위한 제안이다.
확정된 범위는 끝까지 진행한다. 인터뷰 후 요구사항과 비용 조건을 한 번에 정리해 확인받는다. 이후 승인된 범위 안의 일반적인 구현·수정·검증은 반복해서 허락을 묻지 않고 진행한다. 요구사항 변경, 추가 비용, 기존 데이터 삭제가 필요한 경우에만 해당 선택을 확인한다.
사용자가 해야 하는 일은 구체적으로 안내한다. 휴대폰 권한 허용, 계정 로그인, 기기 연결 등 직접 조작이 필요한 단계에서는 화면과 버튼을 기준으로 설명한다. 접근할 수 없는 기기나 계정은 확인했다고 기록하지 않는다.
2 클라이언트 컴퓨터에서 진행할 인터뷰
인터뷰 방식
한 번에 1~3개씩 한국어로 질문한다. 답변에 따라 다음 질문을 조정하고 이미 확인한 내용을 다시 묻지 않는다. 선택이 어려우면 2~3개 안과 추천 이유를 짧게 제시한다. 모르는 항목은 우선 미정으로 남기되, 개발 방향을 바꾸는 항목은 구현 전에 확정한다.
컴퓨터에서 직접 확인할 수 있는 개발 도구 버전과 설치 상태는 먼저 확인한다. 비밀번호, API 키, 인증서 비밀번호를 대화창에 붙여 넣도록 요청하지 않는다.

선택이 어려울 때 제안할 기본안
Android 단일 앱, 로그인 없이 개인 사용, 버튼을 눌러 한 문장씩 말하기, 휴대폰 내 기록 저장을 우선 제안한다. 예약 시 알림을 표시하고 알림을 누르면 첫 문장이 보이도록 한다. 음성 자동 재생과 마이크 시작 시점은 별도로 확인한다. 첫 버전부터 실시간 통화형 대화나 정밀 발음 점수가 필요한지도 확인한다.
인터뷰 완료 조건
개발 전에 다음 내용을 한 번에 제시하고 확인받는다. ① 목표와 필수 기능 ② 이번 버전에서 제외할 기능 ③ 알림과 수업 시작 흐름 ④ 학습 분량과 완료 기준 ⑤ 기술 구성과 서비스 선택 ⑥ 무료 한도와 월 비용 상한 ⑦ 기록·외부 전송 범위 ⑧ 실제 기기 검수 기준. 요구사항 문서에는 확정 사항과 미정 사항을 구분해서 저장한다.
3 학습과 예약 알림의 동작 기준
기본 사용 흐름
일정 저장 → 휴대폰에 예약 등록 → 예약 시각에 알림 표시 → 사용자가 알림 또는 ‘학습 시작’을 누름 → 필요한 경우 잠금 해제 → 해당 수업의 첫 문장 표시 → 합의한 음성 방식으로 학습 → 결과와 복습 내용 저장.
여기서 ‘알림 확인’은 알림 본문이나 학습 시작 버튼을 누르는 행위로 정의한다. 알림창을 펼치거나 알림을 지우는 것만으로 수업 완료나 마이크 시작을 처리하지 않는다. 최초 권한 요청과 잠금 해제 등 운영체제에서 요구하는 단계는 예외로 안내한다.
자동 시작의 범위
예약 시점에는 네트워크나 PC 연결 없이 알림을 표시할 수 있어야 한다. 앱이 백그라운드에 있을 때 화면을 강제로 열거나 잠금을 우회하는 동작을 기본 기능으로 약속하지 않는다. 전체 화면 알람을 원하면 지원 조건을 별도로 검토한다. Android는 백그라운드 화면 실행을 제한하므로 일반 알림을 통한 진입을 우선한다. Android 화면 실행 제약
마이크는 사용자가 앱 화면에서 음성 입력을 시작한 뒤 사용한다. 알림만 도착한 상태에서는 녹음을 시작하지 않는다. 첫 문장 자동 재생을 선택한 경우, 알림을 눌러 진입한 뒤의 재생 동작과 음소거·일시정지 방법을 제공한다.
예약과 예외 처리
정시 알림이 필수라면 정확한 알람 권한을 확인하고 요청한다. 허용되지 않은 상태를 정시 예약 성공으로 표시하지 않는다. 사용자가 허용하면 재등록하고, 거부하면 지연 가능한 알림 또는 수동 시작을 안내한다. 정확한 알람 권한
알림 권한과 알림 채널 상태를 확인한다. Android 13 이상에서는 알림 권한 요청이 필요하다. 차단된 경우 설정으로 이동할 수 있어야 한다. 알림 권한
일정 변경·삭제 시 이전 예약을 취소한다. 재부팅, 시간·시간대 변경, 앱 업데이트 후 필요한 예약을 복원하고 중복을 방지한다. 다음 예약 시각을 화면에 표시한다.
미루기와 건너뛰기는 인터뷰에서 채택한 경우 구현한다. 늦게 누른 알림, 완료한 수업의 알림, 연속 탭으로 잘못된 수업이나 중복 세션이 생기지 않게 한다.
절전·방해금지·제조사 설정·사용자의 강제 중지에 따른 제약은 실제 기기에서 확인한다. 강제 중지 후에는 자동 동작을 보장하지 않으며, 앱을 다시 열었을 때 예약 상태를 복구한다.
첫 버전의 학습 기능
다음 학습 시간과 ‘지금 학습하기’를 제공한다. 수업에서는 상대의 영어 문장, 답변 입력, 선택한 음성 기능, 종료 동작을 제공한다. 피드백과 학습 이력은 인터뷰에서 정한 수준으로 구현한다. 대화 응답은 학습 수준과 주제에 맞추고, 한 번에 대답할 질문을 분명히 한다.
연결 실패나 AI 한도 초과 시 입력한 문장을 보존하고 현재 상태를 설명한다. 내장 연습문제로 전환한다면 ‘기본 연습’임을 표시한다. 고정 문장을 실제 AI 응답처럼 보여주지 않는다. 음성 인식 결과만으로 정밀한 발음 점수를 산출하지 않는다.

비용 통제
운영비 목표는 월 0원으로 시작하되 인터뷰에서 확정한다. Gemini API 등은 후보이며, 개발 시점의 공식 가격표와 해당 계정의 실제 한도를 확인한 뒤 선택한다. 확인 날짜, 모델, 분당·일일 한도, 데이터 사용 조건을 요구사항 문서에 남긴다. 무료 티어는 무제한 이용을 의미하지 않는다. API 가격 · 사용량 한도
하루 학습 횟수 × 수업당 대화 왕복 수에 수업 생성·교정 요청을 더해 필요한 호출량을 계산한다. 대화 문맥과 출력 길이를 포함해 실제 수업 1회로 사용량을 측정한다.
월 0원이 필수이면 결제 연결이 없는 무료 프로젝트를 우선한다. 한도를 넘으면 요청을 멈추거나 합의한 기본 연습으로 전환한다. 유료 모델 자동 전환, 무제한 재시도, 키를 바꿔 한도를 우회하는 동작은 넣지 않는다.
유료 사용을 선택하면 예상 비용과 상한을 먼저 확인받는다. 앱의 사용량 제한이나 예산 알림만으로 공급자 전체의 청구가 완전히 차단된다고 설명하지 않는다.
서버·도메인·클라우드 데이터베이스·유료 음성 API는 필요성이 확인될 때만 추가한다. 초기 무료 크레딧과 지속적인 무료 티어를 구분한다. 개발 도구 구독료와 앱 운영비도 구분한다.
키와 학습 데이터
API 키를 소스, APK, 로그, 문서에 하드코딩하지 않는다. 본인 기기에서 개인 키를 입력하는 방식을 택하면 Android Keystore를 이용해 저장 값을 보호하고 백업에서 제외한다. 기기에 저장된 키를 완전히 숨길 수 있다는 보장은 하지 않는다. 선택한 서비스가 권장하는 클라이언트 연동을 확인하고, 필요한 경우에만 인증된 최소 중계 구성을 검토한다. API 키 보안
대화와 원음의 외부 전송·저장 범위를 설정과 안내에 반영한다. 무료 AI 서비스의 데이터 이용 조건을 확인받고, 원음은 필요성이 합의된 경우에만 보관한다. 공개 저장소나 오류 로그에 키·원음·학습자 개인정보가 남지 않게 한다.
5 Windows 개발 순서와 인계
1단계 환경 확인과 요구사항 확정
프로젝트 파일, Windows 버전, Android Studio·SDK·JDK, 빌드 도구, 휴대폰 연결 상태를 확인한다. 사용하는 Claude 또는 Codex의 실행 위치가 Windows인지 WSL인지 구분하고, 실제 빌드 환경과 파일 경로를 일관되게 정한다. 설치가 필요한 항목만 공식 배포 경로로 안내한다. SDK 라이선스와 휴대폰 권한 등 사용자 조작이 필요한 단계는 따로 설명한다.
2절의 인터뷰를 진행하고 요구사항을 확정한다. 기존 파일을 덮어쓰거나 폴더 전체를 재생성하지 않는다. 다른 작업이 진행 중이면 충돌하지 않도록 작업 위치를 정한다.
2단계 알림부터 실제 기기에서 확인
최소 앱을 빌드해 휴대폰에 설치한다. 짧은 테스트 일정을 등록하고, 앱이 화면에 없는 상태에서 알림을 받은 뒤 해당 수업 화면이 열리는지 확인한다. 이 단계에서 정시 예약, 권한, 잠금 상태, 중복 진입 문제를 먼저 해결한다.
3단계 수업 한 회차 완성
‘지금 학습하기 → 문장 제시 → 사용자 답변 → 응답과 교정 → 종료 → 기록 저장’이 실제로 이어지게 만든다. 선택한 음성 기능과 AI API를 연결해 본인 기기에서 수업을 완료한다. 오프라인·권한 거부·무료 한도 초과에서도 앱이 멈추거나 입력을 잃지 않는지 확인한다.
4단계 일정과 화면 완성
합의한 반복 일정, 설정, 기록, 미루기·복습 기능을 연결한다. 읽기 쉬운 글자와 누르기 쉬운 버튼을 사용하고, 녹음·재생·대기·오류 상태가 구분되게 한다. 필수 기능이 동작한 뒤 화면을 다듬는다. 추가 계정 시스템, 관리자 페이지, 상용 결제 기능은 별도 요청이 있을 때 검토한다.
5단계 개인용 APK 제작과 설치
사용자가 관리할 서명 키로 설치용 APK를 만든다. 패키지 식별자를 유지하고, 업데이트 때는 같은 서명 키와 증가한 버전 번호를 사용한다. 서명 키의 보관 위치와 백업 방법을 안내하되 비밀번호를 문서에 적지 않는다. 기존 앱 위에 업데이트하여 기록과 일정이 유지되는지 확인한다.
APK 직접 설치와 USB 설치 중 해당 기기에서 가능한 방법을 안내한다. 앱스토어 미출시는 Android의 권한·설치 제약을 없애지 않는다. 설치 시점의 국가·기기·개발자 확인 정책을 확인하고, 필요하면 무료 제한 배포 계정의 적용 가능성을 검토한다. 개발자 확인 안내 · 개인용 제한 배포 안내

6 검수 기준과 완료 보고
실제 휴대폰에서 확인할 항목
인터뷰에서 확정한 기능을 기준으로 아래 시나리오를 실행한다. 기기 모델·Android 버전, 권한 상태, 실행 시각, 기대 결과, 실제 결과를 기록한다. 미채택 기능은 해당 없음으로 표시한다. 정시 알림 허용 오차는 인터뷰에서 정하고 실제 예약·도착 시각으로 비교한다.
시나리오
통과 기준
최초 설치
APK 설치와 실행이 성공하고 권한 설명·설정이 정상적으로 동작한다.
PC 종료 후 예약
PC와 개발 도구를 종료해도 휴대폰에서 예약 알림이 표시된다.
화면 꺼짐과 절전
화면을 끄거나 절전 상태로 둔 기기에서 예약을 확인한다. 짧은 테스트 외에 실제 생활 시간대의 예약도 검증한다.
알림에서 수업 시작
알림을 누르고 필요 시 잠금을 해제하면 해당 수업의 첫 문장이 바로 표시된다. 합의한 음성 동작이 이어진다.
알림 중복과 늦은 확인
연속 탭·지난 알림·완료 수업 알림으로 중복 수업이나 잘못된 기록이 생기지 않는다.
일정 변경과 삭제
변경 전 알림이 남지 않고, 다음 회차가 올바르게 표시된다. 채택한 미루기·건너뛰기도 확인한다.
재부팅과 시간 변경
다시 켜거나 시각·시간대를 바꾼 후 합의한 시간 기준으로 예약이 복원된다.
권한 거부와 철회
알림·정확한 알람·마이크 권한을 각각 거부하거나 철회해도 상태 설명과 복구 경로가 제공된다.
강제 중지와 복구
강제 중지 중의 제약을 안내하고, 앱을 다시 열면 필요한 예약을 복구한다.
수업 한 회차
실제 음성 또는 텍스트 입력부터 응답·피드백·종료·기록까지 완료된다. 재실행 후에도 기록이 유지된다.
인터넷과 AI 오류
인터넷 끊김·잘못된 키·한도 초과 시 입력이 보존되고 재시도 또는 합의한 대체 학습이 제공된다.
녹음과 음성 출력
듣기·말하기 상태가 명확하고 정지 버튼이 작동한다. 화면 이탈 시 마이크가 합의한 방식으로 종료된다.
업데이트와 데이터
같은 서명으로 업데이트한 뒤 학습 기록과 일정이 유지되고, 선택한 삭제·백업 기능이 작동한다.
비용과 비밀 값
실제 수업의 사용량을 확인하고 무료 초과 시 유료 전환이 없다. 전달 파일과 로그에 키·비밀번호가 없다.

완료 판단
빌드 성공만으로 완료 처리하지 않는다. 실제 휴대폰에서 예약 알림을 받고, 알림을 눌러 수업을 시작해 한 회차를 끝내고, 기록이 저장되는 것을 확인해야 한다. 필수 시나리오에서 발생한 문제를 해결한 뒤 최종 APK로 다시 확인한다.
기기에 직접 접근할 수 없다면 사용자가 수행할 조작과 기대 결과를 안내하고 결과를 받아 기록한다. 모의 시험이나 코드 검사만 수행한 항목은 실제 기기 검증과 구분한다. 확인하지 못한 항목은 미검증으로 남기고 완료 범위와 함께 보고한다.
마지막 보고에 포함할 내용
설치용 APK와 소스 위치, 구현한 기능, 실제 확인한 기기와 시나리오, 운영 비용 조건, 사용자에게 필요한 남은 조작, 미검증 항목 또는 알려진 제약을 간결하게 정리한다. 설치 이후에도 사용자가 같은 Windows 환경에서 수정·재빌드·업데이트할 수 있게 안내한다.
