# 인터뷰 기록 (진행 중)

최종 확정본은 인터뷰 완료 후 `requirements.md`로 정리한다. 이 파일은 회차별 답변 원본 기록이다.

## 1회차 (2026-09-26)

- 개발 환경: A안 — Claude Code 클라우드 세션(Linux)에서 코드 작성·APK 빌드. 사용자는 APK를 내려받아 휴대폰에 직접 설치. 실기기 검수는 사용자가 수행하고 결과를 전달.
  - 클라우드 환경 네트워크에 `dl.google.com` 허용 완료(2026-09-26 확인).
- 기기: Galaxy S24 Ultra, One UI 8.5, Android 16.
- 작업지시서(.docx) 수령 → `docs/work-order.md`.

## 2회차 (2026-09-26)

### 학습 목표
- 수준: 초급 상 ~ 중급 하.
- 목적: 여행·업무·일상·비즈니스·토론 등 전 영역.
- 관심 주제: 3개 정도 (Claude가 제안 → 확인 필요).
- 한국어: 막힐 때만. 영어 말문을 여는 용도 정도로만 사용.

### 일정
- 매일 14:00 첫 말걸기.
- 하루 1회 대화 연습. 한 회차 5~10분.

### 말걸기 시점의 상태별 동작
- 방해금지(DND) 중: 소리 없이 화면 + 진동만. 화면을 터치하면 음성 시작.
- 무음(매너) 모드: 말을 걸지 않는다.
- 화면에 '패스' 버튼 표시. 패스를 누르면 1시간 뒤 다시 말걸기.
- 재시도는 20:00까지 매 1시간. 20:00 이후에는 그날 말걸기를 끝내고 다음 날 14:00에 다시 시작.
- 대답 없음: 8초 기다린 뒤 1회만 다시 말걸기. 그래도 대답이 없으면 종료하고 1시간 뒤 재시도.
- 이어폰 연결 시: 이어폰으로 말한다.

## 3회차 (2026-09-26)

### 재시도 규칙 보완
- 무음(매너) 모드여서 말을 걸지 않은 경우: 1시간 뒤 재시도 (20:00까지).
- DND 중 화면·진동만 켰는데 30초 안에 터치가 없을 때: 화면을 끄고 1시간 뒤 재시도.
- 그날 회차를 완료하면 남은 재시도를 모두 취소.

### 주제
- 주제 3개: ① 비즈니스와 업무 ② 여행과 일상 ③ 의견과 토론.
- 흐름: 첫 인사 → 오늘 어떤 주제로 이야기할지 사용자에게 영어로 묻기 → 사용자가 고른 주제로 대화.
- '의견과 토론'은 이름으로 묻지 않고, 앱이 정한 구체적인 토론 주제를 선택지로 바로 제시한다(4회차 수정).
  (예: "Should companies adopt a four-day work week?")

### 교정 방식 — A안
- 대화 중: 흐름을 끊지 않고, 자연스러운 표현으로 한 번 되받아 말하기(recast).
- 회차 종료 후: 교정 3개를 한국어로 짧게 요약해 화면에 표시.

## 4회차 (2026-09-26)

- 주제 질문 수정: 오늘 주제를 물을 때 '의견과 토론'이라고 묻지 않고, 구체적인 토론 주제를 바로 제시해 묻는다.
- 교정: A안 (재확인).
- API: 사용자가 기존에 만든 Gemini API 키 사용. 종료 후 요약 모델은 `gemini-2.5-flash-lite`.
- 기록·외부 전송: A안 (대화 텍스트만 전송, 음성 원본 저장 안 함, 기록 전체 삭제 제공).
- 앱 이름: 영어자동말걸기. 테마: 휴대폰 설정 따름. 글자: 대화 화면만 크게. 자막: 표시.
- 확정(사용자 "기본안으로 확정"): 월 0원 필수, 대화 응답 모델도 `gemini-2.5-flash-lite`, 완료 기준 5분 또는 약 8왕복, 알람 허용 오차 ±1분.
